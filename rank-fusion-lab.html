The Rank Fusion Lab

Two ranked lists. One merged order. Follow every contribution.

Reciprocal rank fusion (RRF) combines positions, not raw retrieval scores. For each record, add 1 / (c + rank) from each supplied list that contains it. Ranks start at 1; an absent record contributes zero.

These are schematic records, not a live product evaluation or relevance judgements. The starting lists reproduce Table 10.1 and Figure 10.2. Both lists have equal weight. The conventional constant 60 is not a result count or a universal optimum.

List A (lexical): A, B, C. List B (dense): C, A, D. Both input depths are 3; c = 60; output depth is 4.

      Scores are displayed to five decimal places. Ordering and tie detection use exact fractions, not displayed rounding. Equal scores share a rank (for example 1, 1, 3); ties are displayed in deterministic identifier order, not relevance order.

      What this cannot tell you

      RRF discards raw-score gaps and inherits every input cutoff. “List only” means outside the other supplied list, not irrelevant. Neither a larger fused score nor agreement between routes proves that a record meets an information need.
