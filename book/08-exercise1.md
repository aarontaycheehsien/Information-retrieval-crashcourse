## Application exercise I — Explain a result list without invoking meaning

Part I claims that a great deal of apparently intelligent search behaviour is lexical.
This exercise tests that claim against a system you actually support.

1. Choose a discovery layer or database your library licenses.
   Run a natural-language query of six to eight words—a real question, not a keyword string.
2. Record four observations: the reported result count; how many records you can actually page through; whether every query term appears somewhere in the first result; and what happens to the count when you add one invented word to the query.
3. For each observation, list plausible explanations from Chapters 2 to 4.
   State what evidence supports each, what alternatives remain, and which product details would be needed to decide among them; if query understanding may have mattered, name the later change or decision it could have triggered.
4. Repeat the query with every term quoted and joined by `AND`.
   Note what changes and explain what the difference suggests about the execution rule or analyser, without treating the probe as proof of either.

::: {.exercise-deliverable}
**Deliverable.** A one-page note setting out the leading explanation for each observation, supporting evidence, plausible alternatives and remaining uncertainty—and, importantly, listing any observation you could not explain lexically.
If an observation remains unresolved, name the evidence that would help explain it.
As you read Parts II and III, consider which other mechanisms could produce the results you observed.
:::
