The wrong prediction game

[00:00:00.700]: Suppose a model is excellent at recovering hidden words in medical papers. Would you expect it to be an excellent search engine for medical questions? It sounds plausible: it has learnt the vocabulary and can use the surrounding context.

[00:00:18.762]: But a prediction task rewards a particular relationship. Filling a gap in a sentence is not the same task as placing a separately encoded question near a useful answering passage. Start by examining what the model was trained to predict.

[00:00:35.316]: Use the chapter's sentence: The patient received heart treatment after the attack. In our C B O W illustration, hide heart. A local window gives the model patient, received, treatment and after. The target, taken from the original sentence, is heart.

[00:00:53.990]: The neighbouring words supply evidence on both sides. This row illustrates continuous bag of words. Skip-gram uses the opposite direction, predicting neighbouring words from the target word. Neither arrangement requires a person to label the sentence's meaning.

[00:01:11.766]: Now hide treatment. A masked-language objective can use the words before and after that position to recover the missing token. BERT's pretraining chiefly uses this kind of bidirectional prediction to learn broad language patterns.

[00:01:26.449]: Our word boxes simplify a task that operates on model tokens. The answer comes from the text itself, which makes this self-supervised learning. The available context and the target define the prediction problem; self-attention is the mechanism that combines information.

[00:01:45.223]: For next-token prediction, show only The patient received heart treatment. The next target is after. Everything to the right is unavailable to the model at that prediction step. Revealing the next token in the input would give away the answer.

[00:02:00.569]: GPT-style training uses preceding context this way. Historically, bidirectional encoders often started retrieval models and decoders often powered generation. That division has blurred. An architecture family alone does not establish a present-day model's task or role.

[00:02:21.512]: Pretraining learns broad language patterns. Domain pretraining changes the material behind those patterns. Retrieval-oriented training rewards relationships useful for the search task, such as a question and a relevant passage.

[00:02:37.289]: That retrieval signal need not be a human relevance label. It can come from human judgments, behavior, weak labels, synthetic labels or self-supervised pairs. Ask what those examples and targets teach the model to preserve, and how well that transfers to the searches you care about.

[00:02:57.648]: The chapter distinguishes three domain examples. BioBERT continues pretraining on biomedical literature. BiomedBERT starts with biomedical text and vocabulary. SciBERT learns from scientific literature. These choices change the language experience behind the representations.

[00:03:17.859]: They do not by themselves specify which query should rank near which passage. Generic BERT has no direct requirement from masked-word prediction to make those independent embeddings useful for retrieval. Sentence-BERT changes architecture and training to make complete-text representations useful for comparison.

[00:03:39.900]: A product can use a BERT-family model to interpret a query, to produce vectors for first-stage retrieval, or to compare records in an existing shortlist as a reranker. These positions expose the model to different inputs and give it different responsibilities.

[00:03:57.088]: A family name therefore leaves the pipeline open. Knowing that BERT appears somewhere does not tell you how the whole collection was searched, what candidates reached a later stage, or whether the model was trained for that particular retrieval task.
