# Narrated information-retrieval video series

48 original narrated, captioned videos covering the preface and Chapters 1–15 of Aaron Tay’s *How Search Decides What You See*, adapted from the `more-readable` branch.

The MP4s and 16 complete chapter ZIPs are stored with Git LFS. Original production notes describe local generation; this publication adds the reviewed exports. Each ZIP includes its watch gallery, captions, transcripts, storyboards, posters and verification reports.

For a full local checkout, install [Git LFS](https://git-lfs.com/), clone this branch and run `git lfs pull`. Open an extracted ZIP’s `index.html`, or serve a chapter folder with a local HTTP server.

Adapted from Aaron Tay under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Original illustrations and standard synthetic narration; no presenter likeness or cloned voice. Production notes and source snapshots accompany the committed production tools.
